# 同步 FIFO 设计说明

## 1. 概述

模块 `fifo` 是一个单时钟同步 FIFO，用于暂存数据。数据按照写入顺序读出，先写入的数据先读出。

RTL 文件为 [`rtl/fifo.v`](../rtl/fifo.v)。文件中使用了 SystemVerilog 语法，编译时需要启用 SystemVerilog。测试安排见 [验证计划](verification_plan.md)。

主要功能：

- 每个时钟周期最多写入一个数据、读出一个数据。
- 支持同一个时钟周期内读写。
- 满时禁止写入，空时禁止读取。
- 使用 `full`、`empty` 表示 FIFO 是否满、是否空。
- 满时写入产生 `wr_error`，空时读取产生 `rd_error`。
- 高电平异步复位。

## 2. 参数

| 参数 | 默认值 | 说明 |
|---|---:|---|
| `width` | 8 | 每个数据的位宽，必须大于等于 1 |
| `depth` | 16 | 最多存放的数据个数，必须大于等于 2，且为 2 的幂 |

例如，`depth` 可以取 2、4、8、16、32。FIFO 可以存放完整的 `depth` 个数据。

参数在编译时设置，不能在运行中修改。RTL 使用 `$fatal` 检查非法参数。不过，`depth=0` 等配置也可能因为数组或位选范围不合法，先在编译阶段报错。

## 3. 接口

| 信号 | 方向 | 位宽 | 说明 |
|---|---|---:|---|
| `clk` | input | 1 | 工作时钟，上升沿进行读写 |
| `rst` | input | 1 | 高电平有效的异步复位 |
| `wr_en` | input | 1 | 写使能 |
| `wr_data` | input | `width` | 写入数据 |
| `rd_en` | input | 1 | 读使能 |
| `rd_data` | output | `width` | 读出数据 |
| `full` | output | 1 | FIFO 满时为 1 |
| `empty` | output | 1 | FIFO 空时为 1 |
| `wr_error` | output | 1 | 本次写操作因 FIFO 已满而失败 |
| `rd_error` | output | 1 | 本次读操作因 FIFO 为空而失败 |

读写使能和写数据需要在时钟上升沿前稳定。本文所说的“上升沿后”，是指寄存器和相关组合逻辑完成更新后。

## 4. 复位

`rst` 从 0 变成 1 时，不需要等待时钟上升沿，FIFO 就会复位：

| 信号或内部状态 | 复位后的值 |
|---|---|
| 写指针 `wr_ptr` | 0 |
| 读指针 `rd_ptr` | 0 |
| `rd_data` | 全 0 |
| `empty` | 1 |
| `full` | 0 |
| `wr_error` | 0 |
| `rd_error` | 0 |

`rst=1` 期间，即使读写使能为 1，也不进行读写，错误信号保持为 0。释放复位后，从下一个时钟上升沿开始正常工作。

复位不清空 RAM，但复位前尚未读出的数据全部作废。释放复位后，必须先重新写入，才能读到有效数据。

仿真开始时需要施加复位；释放复位应避开时钟上升沿。

## 5. 写操作

写操作成功的条件是时钟上升沿前 `wr_en=1` 且 `full=0`：

```systemverilog
wr_valid = wr_en && !full;
```

在该上升沿，`wr_data` 写入当前写地址，写指针加 1。如果 FIFO 一直没有满，`wr_en` 可以连续保持为 1，每拍写入一个数据。

当 FIFO 已满且 `wr_en=1` 时，本次写操作失败：RAM 不写入，写指针不变，上升沿后 `wr_error=1`。被拒绝的数据不会保存在 FIFO 中。

`wr_en=0` 时，不写 RAM，写指针保持不变。

## 6. 读操作

读操作成功的条件是时钟上升沿前 `rd_en=1` 且 `empty=0`：

```systemverilog
rd_valid = rd_en && !empty;
```

在该上升沿，最早写入且尚未读出的数据更新到 `rd_data`，读指针加 1。读数据在本次上升沿后就能看到，不需要再等一个上升沿。

除了复位，只有成功读取时才更新 `rd_data`：

- `rd_en=0` 时，`rd_data` 保持原值。
- FIFO 为空且 `rd_en=1` 时，读指针和 `rd_data` 保持原值，上升沿后 `rd_error=1`。
- 向空 FIFO 写入数据后，`rd_data` 不会自动显示这个数据，仍需发起一次有效读取。

接口没有额外的读数据有效信号。使用者根据上升沿前的 `rd_en && !empty` 判断本次是否读到了新数据。

## 7. 空满标志

FIFO 没有数据时，`empty=1`；存有 `depth` 个数据时，`full=1`。其余情况下，两者均为 0。正常工作时，两者不能同时为 1。

从空状态连续写入、不进行读取，第 `depth` 个数据写入后 `full` 变为 1。最后一个数据读出后，`empty` 变为 1。这两个标志随本次读写结果更新，不额外延迟一个周期。

## 8. 同时读写

读写是否成功，分别根据上升沿之前的空满状态判断。

| 上升沿前的状态 | 写操作 | 读操作 | 数据个数变化 | 上升沿后的错误信号 |
|---|---|---|---:|---|
| 非空非满 | 成功 | 成功 | 不变 | 两者为 0 |
| 空 | 成功 | 失败 | 加 1 | `rd_error=1`，`wr_error=0` |
| 满 | 失败 | 成功 | 减 1 | `wr_error=1`，`rd_error=0` |

非空非满时，读出的是原来排在最前面的数据，新数据写到最后。即使 FIFO 中只有一个数据，读出的也是原来的数据。

空时同时读写，新写入的数据不会在同一拍直接输出。满时同时读写，不能利用这次读取腾出的位置完成写入；如果还要写这个数据，需要在后续周期重新发起写请求。

例如，复位后进行以下操作，A、B 为两个不同的数据：

| 周期 | 操作 | 操作后数据个数 | 操作后 `rd_data` | `wr_error` | `rd_error` |
|---|---|---:|---|---:|---:|
| 1 | 写 A，同时读 | 1 | 0，保持复位值 | 0 | 1 |
| 2 | 写 B，同时读 | 1 | A | 0 | 0 |
| 3 | 只读 | 0 | B | 0 | 0 |
| 4 | 只读 | 0 | B，保持不变 | 0 | 1 |
| 5 | 不读不写 | 0 | B，保持不变 | 0 | 0 |

## 9. 错误信号

两个错误信号都是寄存器输出。非复位时，每个上升沿根据更新前的状态重新计算：

```systemverilog
wr_error <= wr_en && full;
rd_error <= rd_en && empty;
```

因此，FIFO 满但没有写请求时，`wr_error=0`；FIFO 空但没有读请求时，`rd_error=0`。

连续多拍满写或空读，对应错误信号可以连续为 1。下一拍不再发生对应错误时，信号清零，不需要复位。

满时同时读写后，可能出现 `full=0`、`wr_error=1`：这表示本拍读取成功，但写入时 FIFO 仍是满的。空时同时读写后的 `empty=0`、`rd_error=1` 也是同样的原因。

## 10. 存储器和指针

当前 RTL 使用数组保存数据，读写指针各比地址多一位：

```systemverilog
addr_width = $clog2(depth);
ptr_width  = addr_width + 1;
```

指针低位用作 RAM 地址，最高位用于区分空和满：

- 读写指针全部相同，FIFO 为空。
- 低地址位相同、最高位不同，FIFO 为满。

每次成功读写，对应指针加 1；操作失败或没有操作时，对应指针不变。地址从 `depth-1` 回到 0 时，最高位翻转。整个指针每经过 `2*depth` 次成功操作回到原值。

多次回卷后，数据顺序仍须正确，不能丢失、重复或覆盖尚未读出的数据。

## 11. 不支持的功能

本设计不支持双时钟 FIFO、非 2 的幂深度、首字直通（FWFT）、空时同拍写读直接输出、满时同拍读写替换数据，以及运行中修改参数。RAM 宏、面积、功耗和物理时序不在本说明范围内。
