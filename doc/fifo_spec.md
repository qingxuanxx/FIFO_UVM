# 同步 FIFO 功能规格（Spec）

本文规定 `fifo` 的外部可观察行为，作为 RTL 实现和验证的共同依据。当前实现为 [`rtl/fifo.v`](../rtl/fifo.v)，验证方法见 [Verification Plan](verification_plan.md)。条款 ID 用于需求追踪；文档中的要求不代表已经验证通过。

## 1. 范围与参数

FIFO 使用单一时钟，按成功写入的顺序保存和读出数据，每拍最多接受一次写入和一次读取。全部 `depth` 个位置均可使用。

| 条款 | 参数 | 默认值 | 合法范围 |
|---|---|---:|---|
| S01 | `width` | 8 | 整数，`width >= 1` |
| S01 | `depth` | 16 | 整数，`depth >= 2` 且为 2 的幂 |

参数在 elaboration 时确定，运行期间不可改变。RTL 使用 SystemVerilog 语法，尽管后缀是 `.v`，仍需按 SystemVerilog 编译。

**S02 — 非法参数：** 非法配置必须被拒绝，不能进入正常功能仿真。当前 RTL 在 `initial` 中调用 `$fatal` 检查参数。由于数组维度和切片也依赖参数，部分非法配置可能先在编译或 elaboration 阶段被工具拒绝，不能保证所有非法配置都执行到 `$fatal`。诊断及验证规则见 vPlan。

## 2. 接口与时序约定

| 信号 | 方向 | 位宽 | 含义 |
|---|---|---:|---|
| `clk` | input | 1 | 工作时钟，上升沿处理请求 |
| `rst` | input | 1 | 高电平有效的异步复位 |
| `wr_en` | input | 1 | 本拍写请求 |
| `wr_data` | input | `width` | 本拍待写入的数据 |
| `rd_en` | input | 1 | 本拍读请求 |
| `rd_data` | output | `width` | 最近一次成功读取的数据，复位时清零 |
| `full` | output | 1 | 当前有效数据量等于 `depth` |
| `empty` | output | 1 | 当前有效数据量等于 0 |
| `wr_error` | output | 1 | 最近一个工作上升沿拒绝了写请求 |
| `rd_error` | output | 1 | 最近一个工作上升沿拒绝了读请求 |

**S03 — 采样与更新：** `rst=0` 时，DUT 在 `clk` 上升沿采样请求和写数据。本文以 `pre` 表示该沿处理前的状态，以 `post` 表示该沿非阻塞赋值（NBA）及组合逻辑稳定后的状态。所有读写接受条件均使用 `pre` 状态。

环境必须在采样沿附近保持请求稳定；写请求有效时，`wr_data` 必须为确定值。正常功能不定义 X/Z 输入下的结果。时钟频率、建立/保持时间和复位恢复/移除时间不属于本 RTL 功能规格；仿真应避开工作上升沿释放复位。

接口没有 `rd_valid` 输出。下游通过沿前的 `rd_en && !empty` 判断本拍读数据是否有效。

## 3. 复位契约

**S04 — 异步复位及优先级：** `rst` 上升时无需等待 `clk`，在仿真更新稳定后必须满足：

| 状态或输出 | 复位值 |
|---|---|
| 逻辑有效数据量 | 0 |
| `empty` / `full` | 1 / 0 |
| `rd_data` | 全 0 |
| `wr_error` / `rd_error` | 0 / 0 |

复位优先于读写请求。`rst=1` 期间，不论使能如何变化，工作时钟沿均不得接受读写，以上状态保持。复位释放本身不执行请求，从释放后的第一个上升沿恢复正常工作。

**S05 — 数据失效：** 任何一次复位都会丢弃所有尚未读出的数据。存储数组无需清零，复位前的内容不得作为复位后的有效 FIFO 数据读出。上电后必须施加有效复位，复位前不保证状态有效。

## 4. 逐拍行为

令 `Q_pre` 为沿前有效数据队列，`N_pre` 为其长度，`D_pre` 为沿前 `rd_data`。以下公式仅适用于 `rst=0`：

```text
full_pre  = (N_pre == depth)
empty_pre = (N_pre == 0)
W = wr_en && (N_pre < depth)
R = rd_en && (N_pre > 0)
N_post = N_pre + W - R
```

**S06 — 写入：** `W=1` 时，在本拍将 `wr_data` 加入队尾；`W=0` 时不增加数据，也不覆盖已有有效数据。使能连续有效且沿前非满时，每拍接受一个数据。

**S07 — 同步读取与保持：** `R=1` 时，在本拍移除沿前队首，并在该沿更新后将队首数据输出到 `rd_data`。无额外工作时钟延迟。除复位外，`R=0` 时 `rd_data` 必须保持 `D_pre`，包括空读、只写和空闲周期。该接口不是 FWFT，写入非空 FIFO 不会自动更新读输出。

**S08 — 数据完整性：** 未被复位丢弃的每个成功写入项必须按写入顺序且仅一次被成功读出；被拒绝的写入不能进入有效数据序列。

**S09 — 空满标志：**

```text
empty_post = (N_post == 0)
full_post  = (N_post == depth)
0 <= N_post <= depth
```

空满标志反映当前状态，不额外延迟一拍。第 `depth` 次净写入后即满，读出最后一个数据后即空。正常复位后的有效运行中，`full` 和 `empty` 不得同时为 1。

**S10 — 错误输出：**

```text
wr_error_post = wr_en && (N_pre == depth)
rd_error_post = rd_en && (N_pre == 0)
```

错误为寄存器输出，每个工作上升沿重新计算，不是粘滞标志。连续拒绝请求可使其连续为 1；下一拍没有对应拒绝时必须清零。错误与沿前状态有关，因此 `wr_error_post=1` 可以与 `full_post=0` 同时出现，`rd_error_post=1` 也可以与 `empty_post=0` 同时出现。

### 4.1 完整请求矩阵

表中状态均为沿前状态，错误列为沿后值；复位行为优先于本表。

| 沿前水位 | `wr_en rd_en` | 写接受 W | 读接受 R | 水位变化 | `wr_error rd_error` |
|---|---|---:|---:|---:|---|
| 空：0 | 00 | 0 | 0 | 0 | 00 |
| 空：0 | 10 | 1 | 0 | +1 | 00 |
| 空：0 | 01 | 0 | 0 | 0 | 01 |
| 空：0 | 11 | 1 | 0 | +1 | 01 |
| 中间：1 到 depth−1 | 00 | 0 | 0 | 0 | 00 |
| 中间：1 到 depth−1 | 10 | 1 | 0 | +1 | 00 |
| 中间：1 到 depth−1 | 01 | 0 | 1 | −1 | 00 |
| 中间：1 到 depth−1 | 11 | 1 | 1 | 0 | 00 |
| 满：depth | 00 | 0 | 0 | 0 | 00 |
| 满：depth | 10 | 0 | 0 | 0 | 10 |
| 满：depth | 01 | 0 | 1 | −1 | 00 |
| 满：depth | 11 | 0 | 1 | −1 | 10 |

**S11 — 同拍读写：** 中间水位时读出旧队首，再将新数据加入队尾；即使水位只有 1，读出的也必须是旧数据。空时不旁路，新写入项最早在后续工作沿读出。满时不利用同拍读取释放的位置，写请求被拒绝；如仍需写入，环境必须在后续周期重新提出请求。

### 4.2 空 FIFO 同拍读写示例

假设 A、B 为不同的 `width` 位数据，起始状态已复位。

| 工作沿 | 沿前水位 | 请求 | 沿后水位 | 沿后 `rd_data` | 沿后 `wr_error rd_error` |
|---|---:|---|---:|---|---|
| k | 0 | 写 A，同时读 | 1 | 0（保持） | 01 |
| k+1 | 1 | 写 B，同时读 | 1 | A | 00 |
| k+2 | 1 | 只读 | 0 | B | 00 |
| k+3 | 0 | 只读 | 0 | B（保持） | 01 |
| k+4 | 0 | 空闲 | 0 | B（保持） | 00 |

## 5. 当前 RTL 的实现约束

本节为白盒检查提供依据；外部功能预测仍应使用第 3、4 节的队列语义。

**S12 — 指针与回卷：** 当前实现使用 `mem[depth-1:0]` 和两个扩展指针：

```text
addr_width = $clog2(depth)
ptr_width  = addr_width + 1
```

低 `addr_width` 位用于寻址，最高位为回卷位。复位清零两个指针；每个指针仅在对应请求被接受时按 `ptr_width` 位模运算加 1，否则保持。

指针全位相同表示空；低地址相同、最高位相反表示满。地址从 `depth-1` 回到 0 时最高位翻转。地址回卷每 `depth` 次成功操作发生一次；完整扩展指针回卷每 `2*depth` 次成功操作发生一次。任意多次回卷后仍须满足数据完整性要求。

## 6. 范围之外

不支持异步双时钟或 CDC、非 2 的幂深度的正常运行、FWFT、空时旁路、满时同拍替换、动态参数、almost-full/almost-empty、ECC 或错误粘滞记录。本规格不约束 RAM 宏映射、综合面积、功耗或物理时序。
